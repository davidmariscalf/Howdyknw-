Cómo conectar una TV alejada

Instala y abre Howdyknw en la televisión que está lejos. Usa la misma dirección segura de este servidor en la TV y en el móvil receptor. No hace falta compartir Wi-Fi ni abrir puertos en el router si alojas el servidor en Internet.

—

Esta prueba comprueba HTTP y WebSocket; no activa ni envía audio.

En la app Android TV pega la dirección WSS y el mismo código de sala que en el receptor. Para Tizen usa la dirección HTTPS. La TV debe permitir y activar el micrófono; cerrar la app corta el audio. Si no está disponible, solo se puede compartir texto por el teclado del sistema.

Si esta web muestra localhost o una dirección local, todavía necesitas publicar el servidor mediante HTTPS. No expongas un servicio sin contraseña ni reutilices códigos de sala compartidos.

EMPEZAR A CAPTURAR

Desde un ordenador con TShark

El equipo de captura debe poder ver el tráfico de la TV: por ejemplo, en el router, un puerto espejo o un punto de acceso propio. Estar en el mismo Wi-Fi no garantiza verlo.

python tv_monitor.py --interface 1 --tv-ip 192.168.1.50 --duration 180

El equipo de captura debe estar en la ruta del tráfico.

Sustituye la interfaz y la IP por las tuyas. También puedes analizar una captura existente con --pcap archivo.pcapng. El informe aparece aquí si se ejecuta junto al servidor, o puedes importarlo como JSON.

Qué se puede y no se puede saber

Se observan direcciones IP, dominios DNS/SNI cuando aparecen, puertos y volúmenes aproximados. El contenido HTTPS cifrado, consultas DNS cifradas y tráfico que no pasa por tu punto de captura no son visibles.
